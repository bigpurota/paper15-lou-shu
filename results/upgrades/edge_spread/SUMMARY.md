- Non-cost часть ln A: незначим (|t| < 1.96 < 3 HLZ); cost часть: незначим (|t| < 1.96 < 3 HLZ). Картина статьи (прайсится только non-cost часть) на наших данных статистически не воспроизводится.

## Оговорки
- EDGE — оценка по дневным свечам, а не наблюдаемый спред; для ликвидных монет истинный спред мал и оценка шумная (отсюда отрицательные s²). ТЗ (task.md, стр. 59) предполагает часовые бары — это отступление.
- Крипта торгуется 24/7: медианный |open − close предыдущего дня| = 3.3 bp (open = прошлому close в 35% дней) при медианном дневном размахе high−low 723 bp. Медианный вес второго момента EDGE (на этом разрыве) = 0.9996: оценка почти целиком определяется отскоком между последней сделкой дня и первой сделкой следующего.
- T10, cost-часть: Cost = a_t + b_t·ln EDGE, поэтому месячный коэффициент = (коэф. ln EDGE)/b_t. Наклон b_t < 0 в 10% месяцев, min |b_t| = 0.0005; месячные коэффициенты при cost: медиана -0.96, макс. |·| 831. Среднее FM по cost-части определяется несколькими месяцами — сравнивать со статьёй можно только t, не величину.
- Издержки: основная оценка — только полуспред (комиссия — отдельной строкой выше); без price impact крупного объёма и стоимости/доступности шорта (многие неликвидные монеты нельзя занять).
- Разложение ln A на cost/non-cost оценивается на панели монет с доходностью в t (как и FM), а не на полном сечении t−2.
