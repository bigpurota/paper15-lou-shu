Base run: `20261016T221825Z_3e8eb87e`; upgrade run: `20261016T221957Z_amihud_noh`; git `06cc8d82`. Every number below is generated by code (`src/amihud_noh.py`) from the CSVs in this folder.

## What we tested
- `ILLIQ = LSIlliq + cov(|r|, 1/DVol)`: Lou & Shu implicitly set the covariance to zero. `DIF = lnILLIQ − ln|R| − lnIDVOL` is the omitted term (A&N, eqs. 6–8).
- (a) monthly measures of the base panel; (b) 12-month A&N measures (≥200 days, the single highest day excluded, 1% censoring), lagged 2 months; (c) the IVOL channel; (d) the verdict. FM, Newey–West with 6 lags, controls Ret[−12,−2] and Ret[−1]; the main dependent variable is the CMKT-adjusted return (`ret_adj`), the raw return (`ret`) is a robustness check.

## Premise: is the covariance negative?
- Monthly measures: share of coin-months with COV<0 = 0.988; mean DIF = -0.244 (t = -27.67); corr(DIF, lnA) = 0.005.
- 12 months: share COV<0 = 1.000; mean DIF = -0.326 (A&N: -0.17); corr(DIF, lnILLIQ) = -0.067 (A&N: -0.37); share b≤0 = 0.000 (A&N: 0.011); R² of DIF on (lnCV², ln b, lnLSIlliq) = 0.26 (A&N: 0.45); corr(DIF, ln(1−b·CV²/LSIlliq)) = 0.157.

## Caveats
- The LS prediction for Res.lnA / RlnILLIQ (V3, V5) is coded as '−/0': LS (2017, Introduction) write that the coefficient on the residual measure is 'either insignificant or significantly negative'. It was corrected from '−' during verification; the rule does not depend on this (it compares only significant results); only the labels change from 'neither' to 'LS (H0 not rejected)'.
- The tests are not independent. Since lnILLIQ = ln|R| + lnIDVOL + DIF, the model [lnIDVOL, RlnILLIQ, ln|R|] is a reparametrisation of col. 3: the 12-month RlnILLIQ coefficient = 14.115 (t 1.55), DIF in col. 3 = 14.115 (t 1.55). V1–V5 use the same regressors in different combinations and are strongly dependent; the 'who wins' count is descriptive, not a formal test.
- In the monthly panel the signals are winsorised separately (base run), so the identity lnA = ln|Ret| + lnA_C + DIF fails in 6.6% of coin-months: monthly C2 Res.lnA = -1.263 (t -0.38) vs DIF in col. 3 = -1.638 (t -0.44).
- 12 months: the cross-sectional spread of ln|R| is small (sd = 0.17 vs 1.28 for lnIDVOL; A&N: 0.34 and 1.89), so corr(lnILLIQ, lnIDVOL) = 0.990 (A&N: 0.99, so this is not specific to crypto). Beyond volume, ILLIQ carries only ln|R| and DIF.
- IVOL in the 12-month models is the base IVOL (12 months, window ending at s = t−2, residuals on the daily EW CMKT, not FF3 as in A&N).
- No Size or B/M control (D2, D3): A&N and LS have them; ln A_C partly plays the role of size.
- Months with measures: 93; FM months: 80–87 vs 588 (LS) and 744 (A&N): power is lower, so the HLZ bar t>3 is shown next to 1.96.
- `b` and CV² use all days of the window (A&N, fn. 10, do not say whether the highest day is excluded for them); for ILLIQ, |R| and IDVOL the single highest day of each is excluded. The 1% censoring is on ILLIQ, |R|, IDVOL and DIF (there is no Size).
- Specification search: every model of this upgrade (fm.csv, both dependent variables, 4 fDIF variants) is reported in full. git does not show that the specification or the verdict rule predates the results (code and results were committed together); only the monthly DIF model (V1 monthly) was in the code before the first real-data run.
- Robustness on raw returns: rows with `dep = ret` in `verdict.csv` and `fm.csv`.
