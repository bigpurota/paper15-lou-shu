4. Размер теста в мире 0 и минимальный обнаружимый эффект (MDE) при мощности 80%.

## Множественные тесты

В семейство входят только строки с ролью `test`, без повторов одной и той же t-статистики. Не входят: `control` (контроли FM, нагрузки на факторы, интерцепты), `placebo` (перемешивание), `diagnostic` (лаг 0, проверка утечки: там большой |t| ожидаем), `descriptive` (отдельные квинтили, описательные моменты), `measurement` (первая ступень оценки меры по монете-месяцу).

- Только базовый прогон (крипто, Lou–Shu): уникальных тестов 73; |t|>1.96 у 16 (при всех нулевых ожидалось бы ≈3.7); |t|>3 у 0. После Бонферрони (порог |t|>3.40) значимы 0, после BH (q<0.05) — 0.
  Из этих 16 тестов с |t|>1.96 12 — варианты одной гипотезы про Res.A/ResLnA (сырые доходности, подпериоды, взвешивание, винзоризация, модели с контролями), т. е. сильно коррелированы, а не независимы. С размером NW(6) из мира 0 (в среднем 7.9% вместо 5%) при всех нулевых ожидалось бы ≈5.7 из 73; из-за корреляции тестов разброс этого числа намного больше биномиального.
- Всё: база и все апгрейды (включая США и варианты): уникальных тестов 750; |t|>1.96 у 191 (при всех нулевых ожидалось бы ≈37.5); |t|>3 у 66. После Бонферрони (порог |t|>3.99) значимы 14, после BH (q<0.05) — 90.

## Размер теста и мощность (симуляции)

Мир 0 (премии нет): доля |t|>1.96 — fm2_lnA_C 8.0%, fm3_ResLnA 9.5%, hl_A_C 6.5%; доля |t|>3 — fm2_lnA_C 1.5%, fm3_ResLnA 1.5%, hl_A_C 1.0%. Эмпирический 5%-й порог |t| в мире 0: fm2_lnA_C 2.21, fm3_ResLnA 2.15, hl_A_C 2.10.

MDE при мощности 80% (оценки):
- по симуляционной кривой мощности (|t|>1.96), FM lnA_C модель 2: 0.44 %/мес на 1 s.d. (диапазон по 95% ДИ мощности [0.38; 0.80]); H–L A_C: 0.47 %/мес на 1 s.d. (единицы премии симуляции, не H–L).
- пересчёт симуляции на наш N×T (√(N·T)-масштаб), FM lnA_C: 0.44 %/мес на 1 s.d.; с порогом мира 0: 0.49.
- по стандартной ошибке нашей реальной оценки (NW): FM lnA_C — 2.15 %/мес на 1 s.d.; H–L A_C — 4.27 %/мес (бутстрап-SE: 4.66).
- MDE по реальной SE / MDE по симуляции (FM lnA_C) = 4.85: симуляция существенно недооценивает шум реальных доходностей, опираемся на MDE по реальной SE.

- H–L A_C, %/мес: эффект статьи 0.61, наш MDE 4.27 (в 7.0 раза больше) — наша выборка эффект такого размера с мощностью 80% не обнаруживает; незначимость у нас не доказывает отсутствия премии.
- FM lnA_C (2), %/мес на 1 s.d. (s.d. ln A_C = 2.53 из текста статьи, с. 13): эффект статьи 0.46, наш MDE 2.15 (в 4.6 раза больше) — наша выборка эффект такого размера с мощностью 80% не обнаруживает; незначимость у нас не доказывает отсутствия премии.

## Оговорки

- Блочный бутстрап с блоком 6 сохраняет автокорреляцию только внутри блока; перцентильный ДИ при 87–93 месяцах приближённый; некруговой MBB недовзвешивает края выборки.
- «на грани» в таблице бутстрапа: граница ДИ так близка к 0, что при других сидах (диапазон нижней границы в `bootstrap_ci.csv`, столбцы ci95_lo_seed_*) ДИ то исключает, то включает 0; такой результат значимым не считаем.
- Пороги мира 0 оценены по 200 повторам; стандартная ошибка доли ложных срабатываний ≈1.9 п.п., 95%-й квантиль |t| тоже шумный.
- Эффект статьи на 1 s.d. берём из её текста (s.d. 2.53); не сказано, объединённое это s.d. или среднее поперечное, у нас — среднее поперечное. Отношение MDE к эффекту статьи — оценка.
- Выкидывание года склеивает соседние месяцы в NW-оценке; бета/CMOM не переоцениваются.
- MDE по симуляции зависит от DGP (шум, число монет); пересчёт на реальный N×T — оценка, не измерение.
- Порог HLZ t>3 дан рядом с 1.96; в мире 0 NW(6) даёт завышенный размер теста, поэтому 1.96 мягче номинала.
