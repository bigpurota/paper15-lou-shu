# Upgrade 2: λ from 5-minute bars signed by taker-buy volume (Binance spot)

_Generated by `src/hf_lambda.py` from the CSVs in this folder. Base run: `20261016T231216Z_3e8eb87e`; run_id: `hf_lambda_20261016T231550Z_3e8eb87e`._

**What we tested.** λ is the slope of the 5-minute log return on SVol (the paper's eq. 11, no intercept). The trade direction comes from the taker-buy volume that Binance reports in each 5-minute kline, i.e. the aggressor side aggregated within the bar (main SVol = √B − √S, robustness sign(B−S)·√|B−S|). The exact trade-by-trade Σ sign·√dvol from aggTrades (isBuyerMaker) is computed only on a validation subsample. We then build analogues of Table 9 (correlations, FM) and Table 10 (cost / non-cost parts of ln A).

**Sample.** Measure months 2023-08…2026-07 (36 months; returns are two months later); coin-months in the base panel 13708, with a 5m file 13708, with λ (≥1000 bars) 13708, of which λ ≤ 0: 3 (the min_bars threshold removed no coin-month, so the min_bars_robust variant equals the main one). **Caveats.** Only 36 return months in FM (the paper has 358), so power is low: an insignificant result does not prove the absence of a premium, and significance over 36 months (one market cycle) does not guarantee stability. Returns use the trade price, not the midquote (spot quotes are not publicly archived), so bid-ask bounce inflates λ for coins with wide spreads. The bar SVol approximates the trade-by-trade SVol (see the validation). Bars with |r| > 0.5 are excluded (319 bars, including real flash crashes). λ ≤ 0 is not dropped; cross-sectional 1/99 winsorisation raises it to the 1st percentile (3 such coin-months). EDGE: used column 'edge' of edge_monthly.parquet (26347 coin-months); main rule 'floor' as in edge_spread, floored share 0.510.

**Test size.** The world-0 calibration of NW(6) (`results/simulations/`, `results/upgrades/robustness/world0_calibration.csv`) was run at 90 months; at T = 36 months the size of the test, and so the meaning of |t| > 3 here, is not calibrated.
